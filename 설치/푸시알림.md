# 푸시 알림 켜기 — 한 번만 하면 된다

앱이 **꺼져 있어도** 새 채팅·업무가 오면 폰에 알림이 뜨게 한다.
브라우저는 저 혼자 꺼져 있을 때 알림을 못 만든다 — 대신 보내 줄 것이 하나 필요하다.
그래서 Supabase 쪽에 작은 함수를 하나 올린다. **전부 브라우저에서 한다. 설치할 프로그램은 없다.**

차례는 다섯이고, 15분쯤 걸린다.

---

## 0. 표부터 (아직 안 했다면)

`설치/표만들기.sql` 을 SQL Editor 에 다시 붙여 넣고 실행한다.
→ 끝에 표가 **13개** 나와야 한다. `gn_구독` 이 새로 생긴 것이다.

이미 있는 표는 안 건드린다. 자료는 안 날아간다.

## 2. 함수를 올린다

Edge Functions → **Deploy a new function** → **Via Editor**

- 이름: `push`  ← 🔴 **꼭 이 이름이어야 한다.** 3번에서 이 이름으로 부른다
- 내용: 저장소의 `supabase/functions/push/index.ts` 를 **통째로** 복사해 붙인다
- **Deploy**

「Verify JWT」 같은 항목이 있으면 **꺼 둔다** — 웹훅이 부를 것이라 로그인 토큰이 없다.

---

## 3. 새 줄이 생기면 함수를 부르게 한다

Database → **Webhooks** → **Create a new hook**

| 칸 | 넣을 값 |
|---|---|
| Name | `새업무알림` |
| Table | `gn_업무` |
| Events | **Insert** 만 켠다 |
| Type | **Supabase Edge Functions** |
| Edge Function | `push` |
| Method | `POST` |

→ **Create webhook**

🔴 Insert 만 켠다. Update 까지 켜면 완료 체크 한 번에 알림이 우르르 간다.

---

## 4. 사람마다 한 번씩 「알림 켜기」

각자 제 폰에서:

1. 앱을 연다 → 홈 오른쪽 위 **제 얼굴**을 누른다 (PC 는 곁줄 맨 아래)
2. **「알림 켜기」**
3. 브라우저가 물으면 **허용**

🔴 **아이폰은 조건이 둘 더 있다.**
- iOS **16.4 이상**
- 사파리 탭이 아니라 **홈 화면에 담은 앱**에서 켜야 한다
  (공유 단추 ↑ → 「홈 화면에 추가」 → 그 아이콘으로 열고 켠다)
안 맞으면 앱이 그 사정을 알려 준다.

갤럭시·PC 크롬은 그냥 켜면 된다.

---

## 5. 되는지 본다

폰에서 앱을 **완전히 닫고**, 다른 기기에서 채팅을 한 줄 보낸다.
→ 폰에 알림이 떠야 한다. 누르면 앱이 열린다.

안 뜨면 Edge Functions → `push` → **Logs** 를 본다. 거기에 까닭이 찍힌다.

---

## 알아둘 것

- **보낸 사람 자신에게는 안 간다.** 제 말에 제가 알림을 받으면 성가시다
- **알림은 기기마다 켠다.** 한 사람이 폰과 PC 를 쓰면 둘 다 켜야 둘 다 온다
- 앱을 지우거나 알림을 끄면 그 구독은 죽는다 — 함수가 그걸 알아채고 조용히 지운다
- 업무 **완료**나 **수정**은 안 알린다(Insert 만 듣는다). 새로 생긴 것만 알린다
- 알림을 끄려면 같은 자리에서 **「알림 끄기」**

## 열쇠를 새로 만들어야 할 때

비밀 열쇠가 샜다고 의심되면 새로 만든다. 만드는 법은 개발자에게 부탁하면 된다
(P-256 키 한 쌍을 base64url 로 뽑는다). 바꾸면 **`js/01f-알림.js` 의 공개열쇠도 같이 바꾸고**,
사람들이 알림을 껐다 다시 켜야 한다 — 옛 열쇠로 맺은 구독은 더는 안 받는다.
